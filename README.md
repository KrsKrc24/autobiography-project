# Autobiography Project

Five life-story posts for PSYC& 200, plus a separate introduction and conclusion. References are on a separate page.

## Preview

Open index.html, or run `python3 -m http.server 8765` in this directory and visit http://localhost:8765.

## Content

The five stories cover early childhood, middle childhood, and adolescence, with nine distinct textbook concepts across those stages. Every story includes imagery, the plasticity theme, context, and reflection. The course theme is plasticity, from slides 35–37 of the supplied Introduction to Lifespan Development deck; curiosity is the personal thread. The pages use childhood photos supplied by Shritan and a portrait and conference photo from International Children’s Wellness. Source credits are included.

Both course textbooks are listed on the references page. Concept citations point to the OpenStax sections used. Overstreet is listed as provided on Canvas. The supplied course slides were checked, and plasticity is explicitly covered.

## Deployment

Static HTML, CSS, and JavaScript; no build step or dependencies. Import this repository in Vercel using the Other framework preset and no build command.

## Privacy

This repository is public. Pages have a noindex tag, but anyone with the link can read them.
